# Portfólio — Paloma Vasconcelos

Site de portfólio de Paloma Vasconcelos, editora de vídeo e proprietária da Triade Kriyo.

[Visitar o portfólio](https://paloma-vasconcelos-portfolio.palomavasconcelos788.chatgpt.site/)

## Conteúdo

- Apresentação e ferramentas de criação.
- Sobre, habilidades e experiência profissional.
- Carrossel com 13 projetos e reprodução de vídeos.
- Contatos profissionais.

## Como executar

O site usa HTML, CSS e JavaScript, sem instalação de dependências ou etapa de compilação. Na pasta do projeto, inicie um servidor estático:

```sh
python3 -m http.server 8000
```

Depois abra http://localhost:8000 no navegador. Use um servidor local para permitir o carregamento de `assets/projects.json`.

## Arquivos

- `index.html`: estrutura e conteúdo.
- `style.css`: estilos e adaptação para dispositivos móveis.
- `app.js`: interações, carrossel e animações.
- `assets/`: imagens, informações dos projetos e vídeos.

As imagens e os vídeos fazem parte do portfólio de Paloma Vasconcelos. Este repositório não concede licença de uso desses materiais.
